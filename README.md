# DevTools

Welcome to DevTools, a collection of tools for various development tasks. This project includes tools for JSON formatting, text comparison, QR code generation, binary conversion, and UUID generation.

## Features

- **JSON Formatter**: Format JSON data easily.
- **Text Compare**: Compare two pieces of text side by side.
- **QR Code Generator**: Generate QR codes from text or URLs.
- **Binary Conversion**: Convert images to different binary formats (binary, hexadecimal, base64).
- **UUID Generator**: Generate unique UUIDs and keep a history.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/D1n5sh1524/devtools.git
   ```

2. Navigate to the project directory:
   ```bash
   cd devtools
   ```

3. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. **JSON Formatter**:
   - Open the project in your preferred IDE or text editor.
   - Navigate to the JSON tab.
   - Paste your JSON data and click "Format".

2. **Text Compare**:
   - Open the project in your preferred IDE or text editor.
   - Navigate to the Text Compare tab.
   - Enter the two pieces of text you want to compare.

3. **QR Code Generator**:
   - Open the project in your preferred IDE or text editor.
   - Navigate to the QR Code tab.
   - Enter the text or URL and click "Generate".

4. **Binary Conversion**:
   - Open the project in your preferred IDE or text editor.
   - Navigate to the Binary Converter tab.
   - Select an image file and choose the desired conversion type (binary, hexadecimal, base64).

5. **UUID Generator**:
   - Open the project in your preferred IDE or text editor.
   - Navigate to the UUID Generator tab.
   - Click "Generate UUID" to generate a new UUID, then click "Copy" to copy it to your clipboard.
