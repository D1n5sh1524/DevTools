# Product Overview

DevTools is a desktop developer utility application — a "Swiss Army Knife" for developers. It bundles several small, standalone tools into a single tabbed GUI window. All processing is 100% local (no network calls).

## Current Tools

- **JSON Formatter** — validate, pretty-print, minify JSON with syntax highlighting
- **TOON Formatter** — convert JSON arrays-of-objects into a compact tabular notation (TOON format)
- **Text Compare** — side-by-side diff with line-, word-, and character-level highlighting
- **QR Code Generator** — generate and download QR codes from text/URLs
- **Binary Converter** — convert image files to binary, hex, or base64 representations
- **UUID Generator** — generate UUID v4 values with timestamped history

## Key UX Principles

- Minimal, warm colour palette (cream/white background, blue accent)
- Keyboard shortcuts: Ctrl+Enter to run primary action, Ctrl+Z for undo
- Tools can be shown/hidden via the header "Tools ▾" picker without losing state
- Status bar per tool communicates success/error/info concisely
